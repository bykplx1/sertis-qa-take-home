# Sertis QA API for Take Home Test

This repo contains source code that is deployed to `https://sertis-qa.glitch.me/` for the QA Take Home assignment for API testing

To edit the deployed source code, go to `https://glitch.com/edit/#!/sertis-qa` (You will need to be added to the Project members list in order to edit it)

## Installation
```
% npm install
```

## Getting started

1. Start a server by executing the command below:

```
% npm start
```

2. Navigate to `http://localhost:3000/` in your browser to see the api doc

3. Use `http://localhost:3000/` as a server url if you'd like to try out the apis locally
